# Russell's Claude plugins

A personal Claude Code plugin marketplace, so cloud Project threads can load the same plugins as the Mac.

| Plugin | Version | Upstream |
| --- | --- | --- |
| context-mode | 1.0.169 | [mksglu/context-mode](https://github.com/mksglu/context-mode). A vendored copy under `plugins/context-mode`, used under the Elastic License 2.0 (see its LICENSE). |

Add it on the Plugins page of a Claude Project as `russellcainiv/claude-plugins`. This repo is private, so Claude's GitHub app needs access to it.
