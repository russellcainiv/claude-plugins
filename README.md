# Russell's Claude plugins

A personal Claude Code plugin marketplace, so cloud Project threads can load the same plugins as the Mac.

| Plugin | Source |
| --- | --- |
| context-mode | [mksglu/context-mode](https://github.com/mksglu/context-mode) (Elastic License 2.0), referenced, not copied |

Add it on the Plugins page of a Claude Project as `russellcainiv/claude-plugins`.
